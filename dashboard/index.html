Following moving objects with radar

A car radar sends back thousands of dots every second. This program groups the dots into objects, gives each object a steady ID, and smooths its path so it can say where the object is heading.

    How it works

    1. Detect

      Read the radar points from all four sensors on the car.

    2. Group

      Points that sit close together (within 1.25 m) become one object.

    3. Match

      Each object is matched to the track it most likely belongs to. A new track is only trusted after three sightings.

    4. Smooth

      A Kalman filter smooths the path and estimates speed and direction.
